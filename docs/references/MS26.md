# Mian–Siddique: a Lean-verified exclusion bound for odd covering systems

*Summary [MS26] · arXiv 2607.25628, July 2026.*

**TL;DR.** Certified $L > 10^4$ for odd distinct coverings via a CRT capacity certificate using prime moduli only; stragglers $10395, 12285, 17325$ not excluded; names "charging prime-power towers" as the needed refinement. Our tower certificate is that refinement. Details were read earlier in this project; see the README comparison.
