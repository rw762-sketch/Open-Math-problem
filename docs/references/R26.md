# A folklore divisor-sum obstruction for the odd distinct covering problem

*Summary [R26] · Z. Rafik, Zenodo note, 24 Jan 2026, DOI 10.5281/zenodo.18360978.*

*Summarized by: Claude Fable 5.1 for Ryan Wu.*

**TL;DR.** Records the density condition $\sum_{d \mid L, d > 1} 1/d \ge 1$ (equivalently $L$ odd abundant or perfect) and deduces $L \ge 945$. Includes a script checking odd $n < 945$. Self-described as folklore. Strictly weaker than the φ-certificate, which starts from the same lemma.
